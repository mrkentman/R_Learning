<h1>Cryptography</h1>

A Collection of R scripts that I've made to encode and decode various forms of cryptography to help me practice my R coding.

1 - [Caesar Cipher](https://en.wikipedia.org/wiki/Caesar_cipher): Simple substitution cipher, where each letter is shifted down the alphabet by a fixed amount.

2 - [Vigenere Cipher](https://en.wikipedia.org/wiki/Vigen%C3%A8re_cipher): A type of [polyalphabetic substitution](https://en.wikipedia.org/wiki/Polyalphabetic_cipher), where each letter of the message is assigned a letter from a keyword, and shifted based on the letter assigned.
